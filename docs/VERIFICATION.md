## 공개 Vercel → Brev/OpenShell 실연동

`node scripts/vercel-smoke.mjs`를 공개 URL에서 실행했다. 임시 합성 프로젝트를 만들며 실제 모델 호출 비용이 발생할 수 있다. 개인 쿠키·서버 키·원본 기록은 저장소에 포함하지 않는다.

- 공개 페이지: 로그인 없이 접속, 익명 서명 세션 시작.
- 실제 런타임: NemoClaw/OpenShell 내부 Node 앱과 NAT 프로세스.
- 모델: `nvidia/nemotron-3-super-120b-a12b`, OpenShell 관리형 추론 경로.
- 연결 검증: 도구가 반환한 새 무작위 토큰을 모델이 다시 반환하는 읽기 전용 왕복 성공.
- 실시간 대화: 실제 `get_project` 호출 성공. 스트림 이벤트 **302개**, 텍스트 delta **296개**, 최초 이벤트 약 **351ms**, 전체 약 **9.3초**. 한 번의 측정이며 성능 보장이 아니다.
- 실제 NAT **1.9.0** 상태 조회 및 저장된 16안 결과 감사 성공.
- 16개 후보 생성 → 16개 반복 시뮬레이션 결과 → 선택안 승인 → CRM 생성·적용 성공.
- 해당 합성 실행에서 CRM **6개 구역, 540개 회차**, 고객 등록 1건, 운영 관측 1건, 개선 제안 1건 생성.
- 새 요청에서 저장 버전과 고객 재조회, 내보내기 성공.
- 다른 익명 세션의 프로젝트 조회 **404**, 잘못된 Origin 변경 요청 **403**, 세션 초기화 전 API **409**.

마지막 성공 검사는 **모델 읽기 도구 + 명시적 로컬 계산/CRM 도구**를 결합한 하이브리드 종단 검사다. 모델이 모든 단계를 자율 계획·실행했다고 주장하지 않는다. CRM 적용은 이 앱 안의 실제 SQLite 운영 구조이며 외부 CRM SaaS 배포가 아니다.

## 관측된 외부 실패

같은 검수 중 NVIDIA 관리형 경로가 간헐적인 **502**를 반환했다. 연결 검사가 실패한 실행, 연결 검사는 통과했지만 대화가 실패한 실행이 각각 있었고 이후 종단 검사가 성공했다. 해당 실패를 숨기거나 로컬 모드로 자동 대체하지 않았다. 앱은 요청 전 5xx에 제한적으로 재시도하며, 이미 노출된 스트림이나 완료한 도구를 자동 재실행하지 않는다. 제공자 가용성·잔액·한도에 대한 SLA는 없다.

공개 샌드박스에서 Overpass 새 시설 조회는 연결에 실패했다. 별도 최소 읽기 요청에서도 연결 취소가 재현되었다. 기존 강의 샌드박스의 네트워크 정책을 변경하지 않았으며, UI는 실패와 기존 스냅샷의 수집 시점을 그대로 표시한다. 저장된 실제 OSM 지형·시설·거리 계산은 사용할 수 있지만 최신 시설 조회를 검증 완료로 간주하지 않는다.

## 스크린샷

README의 화면은 공개 배포에 별도의 합성 프로젝트를 만들어 직접 사용하며 캡처했다. 로그인·키·청구 계정·실제 고객 연락처를 포함하지 않는다. 공간 방문객은 절차적 시각화이며 영상이나 실측 이동 기록이 아니다.

### 비즈니스 온보딩 개편 검수

- 예시/직접 입력 선택, 합성 예시의 16안 실제 계산·지도 분석 저장, 사본 간 독립성, 빈 프로젝트 동작, 잘못된 템플릿 거절 테스트 통과.
- 공간 미확인 상태의 ‘16개 안 생성’, ‘다시’, ‘시뮬레이션 실행’은 실패한 도구 호출 대신 입력 안내를 반환한다.
- 브라우저에서 `30×20m 중정 높이 4m 부스 4개 인력 8명` 채팅 → 수치 카드 반영 → 오너 확인 → 다음 후보 생성 명령 연결을 확인했다.
- 공개 데모에서 준비된 합성 비즈니스에 대한 실제 Nemotron 답변과 `get_project` 도구 완료·대화 저장을 확인했다. 첫 제공자 호출 오류 뒤 명시적인 읽기 전용 재시도는 성공했으나, 이후 상태 요약 요청과 재시도는 다시 실패했다. 외부 모델 가용성 문제는 미해결로 남긴다.
- 같은 프로젝트에서 실제 NAT 결과 감사 → O안 승인 → CRM 빌드·적용(6구역·540슬롯) → 합성 관측 저장 → 개선 가설 1건 생성을 웹 UI로 확인했다. 탭 전환 후 같은 제공자에 대한 명시적 모델 사용 동의도 유지됐다.
- README에서 참조하는 7개 캡처를 모두 `fullPage:false`, **1280×720** 실제 뷰포트로 교체했다. 세로 확장·전체 페이지 합성·이미지 늘이기를 사용하지 않아 고정 헤더가 중간에 끼거나 사이드바 아래가 비어 보이던 문제를 제거했다.
- 기존 오너 프로젝트 이름·목표·대화 기록은 변경하지 않았다. UI와 새 프로젝트 기본값만 오프라인 비즈니스 용어로 변경했다.

## 검증하지 않은 주장

- 현실 방문객 행동·매출에 대한 예측 정확도 또는 인과 효과.
- GPU 자체 NIM 서빙, GPU 성능 측정, 해커톤 필수 기술 인정 여부.
- 외부 CRM·문자·이메일·결제 연동, 다중 사용자 인증·복구, 장기 운영 SLA.
- 제공자의 향후 가용성이나 무제한 무료 사용. 자체 일일 호출 상한은 없지만 공급자 제한과 비용은 적용된다.
