# 운영 관측과 개선 제안

현장 관측은 기간, 표본, 기록 출처, 누락 정도, 현재 적용 중인 CRM 배포 및 입력 리비전과의 일치 여부를 먼저 확인한다. 데이터가 부족하면 원인 단정 대신 어떤 관측을 추가할지 제안한다.

예상과 실제의 차이가 있으면 접수 분리, 사전 등록, 동선 안내, 인력 재배치처럼 실행 가능한 개입을 제안한다. 각 개입의 비용·인력·대기·동의율에 대한 가정을 분리해 재실험하도록 안내한다. 임의로 서비스 시간이나 도착률을 낮춰 성과를 꾸미지 않는다.

관측 기반 제안은 가설이지 검증된 인과 효과가 아니다. 적용 중인 안과 다른 리비전·배포의 제안을 현재 운영에 사용하지 않는다. 제안의 실제 적용·배포는 오너의 승인이 필요한 별도 단계다.
