# 공간 설계와 16안 비교

공간 초안은 미터 단위 치수, 형태, 부스, 인력을 명시한다. 치수 확인 전에는 대안을 생성하지 않는다. 공간이나 실험 가정을 바꾸면 이전 시뮬레이션·승인이 최신 입력과 맞지 않으므로 다시 비교한다.

16개 안은 같은 행사 목표, 기준 공간과 관객·시간·비용 가정에서 비교한다. 완료율만 최적화하지 말고 P90 대기, 총비용, 동의 건수와 예산·목표 제약 통과 여부를 함께 확인한다. 추천안뿐 아니라 제약 때문에 탈락한 안도 이유를 설명한다.

대기열 계산의 반복 결과는 모델 가정에 따른 민감도 범위다. 실제 현장 결과에 대한 통계적 신뢰구간 또는 보장된 예측 정확도라고 말하지 않는다. 3D 인물의 움직임은 시각화이며 성과 계산의 관측 데이터가 아니다.
